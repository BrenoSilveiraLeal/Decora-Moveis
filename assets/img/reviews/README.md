# Fotos demonstrativas das avaliações

Estas imagens foram criadas com a ferramenta integrada `image_gen`, usando os móveis do catálogo como referência. São cenas ilustrativas geradas por IA, identificadas dessa forma nas avaliações. Não representam clientes ou compras reais.

Cada arquivo PNG contém duas linhas por três colunas. Cada linha reúne três ângulos do mesmo produto no mesmo cômodo. A segunda linha mostra outra pessoa, outro ambiente, outra organização, outro percurso de câmera e outra cor. Cada produto exibe duas avaliações e três fotos por avaliação.

Os arquivos desta pasta são: `orbe.png`, `lumo.png`, `aro.png`, `bolha.png`, `cogu.png`, `seixo.png`, `roda.png`, `nicho.png`, `onda.png`, `nuvem.png`, `pingo.png` e `arco.png`. Os prompts usados estão em [prompts.json](prompts.json).

As fotos anexadas pelos visitantes são independentes destas imagens. O formulário aceita até três fotos JPG, PNG ou WebP de até 5 MB cada, prepara versões menores e salva junto com a avaliação no armazenamento local do navegador.
